# Project-4: Basic Chatbot

---

## 📌 Project Description

This project is a simple **rule-based chatbot** developed using Python.

The chatbot interacts with users by recognizing predefined messages and responding with appropriate replies. It continues the conversation until the user enters **"bye"** or **"goodbye"**, making it an excellent beginner project for learning the fundamentals of Python programming.

---

## 🎯 Objective

The objective of this project is to understand how a chatbot works using simple programming logic without Artificial Intelligence.

---

## 🛠️ Technologies Used

- Python 3.14.6
- Visual Studio Code 1.131.0

---

## 📚 Concepts Used

- Functions
- Loops (`while`)
- Conditional Statements (`if`, `elif`, `else`)
- User Input / Output
- String Methods (`lower()`)
- `any()` Function

---

## 📂 Project Structure

```
Project-4-Basic-Chatbot
│
├── chatbot.py
└── README.md
```

---

## ⚙️ How It Works

1. Displays a welcome message.
2. Waits for the user to enter a message.
3. Converts the input to lowercase for easier comparison.
4. Matches the input against predefined rules.
5. Displays the corresponding response.
6. Repeats the conversation until the user types **"bye"** or **"goodbye"**.

---

## 💬 Supported Commands

| User Input | Bot Response |
|------------|--------------|
| hi / hello / hey | Hello! How can I assist you today? |
| how are you | I'm fine. How are you? How can I assist you today? |
| what is your name | I'm a simple Python chatbot. |
| who made you | I was created by Muhammad Ali Haider. |
| what can you do | I can answer simple predefined questions. |
| thank you | You're welcome! |
| bye / goodbye | Goodbye! Thank you for using Basic Chatbot. |
| Any other message | Sorry, I don't understand that. |

---

## 🚀 Features

- ✅ Interactive command-line chatbot
- ✅ Multiple greeting support
- ✅ Handles predefined questions
- ✅ Case-insensitive user input
- ✅ Continuous conversation using loops
- ✅ Beginner-friendly implementation
- ✅ Clean and modular code using functions

---
