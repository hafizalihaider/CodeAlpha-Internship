# Stock Portfolio Tracker

## Overview

Stock Portfolio Tracker is a simple Python console application that allows users to manage a basic stock portfolio. Users can select stocks from a predefined list, enter the quantity of shares they own, and calculate their total investment. The program also generates a formatted text report containing the complete portfolio summary.

---

## Features

- Displays a list of available stocks and their prices.
- Accepts multiple stock purchases.
- Calculates the investment for each stock.
- Calculates the total portfolio investment.
- Prevents invalid stock names.
- Validates numeric quantity input.
- Handles duplicate stock entries by updating the quantity.
- Generates a professionally formatted text report.
- Includes the current date and time in the report.

---

## Technologies Used

- Python 3
- Dictionary
- Loops
- Conditional Statements
- Input Validation
- File Handling
- Date and Time Module

---

## Available Stocks

| Stock | Price ($) |
|--------|----------:|
| AAPL   | 180 |
| TSLA   | 250 |
| GOOGL  | 170 |
| MSFT   | 450 |
| AMZN   | 200 |

---

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:

```bash
python stock_portfolio_tracker.py
```
