# Project-3: Task Automation with Python Scripts

## Overview

This project contains Python scripts developed to automate small,
real-life repetitive tasks.

The main objective of this project is to understand how Python can be
used for file handling, data extraction, and web automation using
built-in libraries and external modules.

---

# Tasks Completed

## Task 1: JPG File Organizer

### Description

A Python script that automatically searches for JPG image files inside
a folder and moves them into a separate folder named **JPG Files**.

### Features

- Scans files from the selected folder.
- Identifies JPG images.
- Creates a destination folder automatically.
- Moves JPG files into the organized folder.
- Displays the number of files moved.

### Concepts Used

- `os` module
- `shutil` module
- File and folder handling
- Conditional statements
- Loops
