# 📧 Email Address Extractor

A simple Python automation script that reads a text file, extracts all valid email addresses using **Regular Expressions (Regex)**, displays them in the terminal, and saves them into a new text file.

---

## 📌 Features

- Reads data from a text file.
- Extracts valid email addresses using Regular Expressions.
- Displays all extracted email addresses.
- Saves the extracted email addresses into a new text file.
- Handles cases where no email addresses are found.

---

## 🛠 Technologies Used

- Python 3.14.6
- Visual Studio Code 1.131.0

---

## 📂 Project Structure

```
Email-Address-Extractor/
│
├── emails.txt
├── Extracted-Emails.txt
├── email-address-extractor.py
└── README.md
```

---

## ▶️ How to Run

1. Place all email addresses inside **emails.txt**.
2. Open the project in Visual Studio Code.
3. Run:

```bash
python email-address-extractor.py
```

4. The program will:
   - Display all extracted email addresses.
   - Create **Extracted-Emails.txt** containing the extracted email addresses.

---

## 📖 Concepts Used

- File Handling
- Regular Expressions (`re`)
- Loops
- Conditional Statements

---

## 📄 Example Input (emails.txt)

```
Contact us:

support@example.com
john123@gmail.com
info@company.org

Thank you!
```

---

## 📄 Example Output

```
support@example.com

john123@gmail.com

info@company.org

Extracted-Emails.txt has been created successfully.
Thank you for using Email Extractor!
```
